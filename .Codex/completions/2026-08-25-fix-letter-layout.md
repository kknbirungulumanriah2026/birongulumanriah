# Fix Letter Layout

- Menambahkan Nomor, Sifat, Lampiran, Perihal, serta Kepada Yth pada preview/cetakan surat.
- Mengubah nomor ke format `140/PPN/{bulan romawi}/BUM/{tahun}`.
- Perihal mengikuti judul template surat.
- Memastikan blok tanda tangan Pangulu rata kanan.
- Validasi `npx tsc --noEmit`, `get_errors`, dan `git diff --check` berhasil.
